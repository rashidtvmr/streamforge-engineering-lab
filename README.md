# StreamForge Engineering Lab

A pull-request-driven, test-first React + TypeScript video SaaS learning project.

The main branch begins as a clean baseline. Review the upcoming numbered pull requests in order; each adds production engineering concepts and their corresponding tests.

## Principles

- Separate domain, HTTP, UI, and infrastructure boundaries.
- Prefer deterministic synthetic data and behavior tests.
- Keep RED/GREEN/REFACTOR commits inspectable when feasible.
- Validate behavior locally and in GitHub Actions before claiming success.
- Do not add personal data or real credentials.
